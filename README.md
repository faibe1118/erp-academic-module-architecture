# 🏛️ Academic ERP System: Curriculum Development Module (Architecture Case Study)

> Comprehensive System Architecture and Software Requirements Specification (SRS) for the Curriculum Development module of a large-scale Academic ERP System.

## 📖 Overview
This repository contains the architectural design and documentation for a case study focused on an Academic ERP. The system's academic management was divided into multiple modules across different engineering teams. 

My team was responsible for the **Curriculum Development Module**, which handles the exclusive operationalization of the curriculum. This involves all processes required to execute the previously defined curricular structure during each academic period.

## 📂 Documentation Included
In the `/docs` folder, you will find:
1. **[Business Context & Constraints](./docs/Business_Context_and_Constraints.pdf):** High-level system requirements and architectural constraints.
2. **[Software Requirements Specification (SRS)](./docs/Software_Requirements_Specification_SRS.pdf):** Detailed functional and non-functional requirements.
3. **[Tech Stack Justification](./docs/Tech_Stack_Justification.pdf):** Detailed analysis of the chosen technologies.
4. **[Architecture Evaluation](./docs/Architecture_Evaluation.pdf):** Assessment of the system's architectural decisions.
5. **[System Manual](./docs/System_Operational_Manual.pdf):** Operational guidelines.
